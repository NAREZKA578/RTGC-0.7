# RTGC-0.7: Реестр файлов и архитектура проекта

Этот документ содержит полный перечень всех файлов исходного кода проекта RTGC-0.7 с подробным описанием их функциональности. Проект написан на языке **Rust** и представляет собой универсальный движок для симуляции транспорта (наземного и авиации) с процедурной генерацией мира.

## 📂 Структура проекта

### 🚀 Точка входа и конфигурация

| Файл | Описание |
|------|----------|
| **`src/main.rs`** | Главная точка входа приложения. Инициализирует окно, создаёт экземпляр движка, запускает игровой цикл (Game Loop), обрабатывает ввод пользователя и координирует работу всех подсистем (рендеринг, физика, ECS). |
| **`src/config.rs`** | Централизованное управление конфигурацией. Содержит структуры для настроек графики (разрешение, VSync, API), физики (шаг времени, гравитация), генерации мира (сид, масштаб) и управления. Загружается из JSON/TOML или устанавливается по умолчанию. |
| **`Cargo.toml`** | Манифест проекта Rust. Определяет зависимости (glow, glutin, nalgebra, serde, rodio и др.), профили компиляции (dev/release), целевые платформы и метаданные проекта. |

---

### 🧠 Архитектура ECS (Entity-Component-System)

| Файл | Описание |
|------|----------|
| **`src/ecs/mod.rs`** | Модуль-агрегатор. Экспортирует публичные типы системы ECS: `World`, `Entity`, `Component`, `System`. Организует структуру пакета ECS. |
| **`src/ecs/world.rs`** | Реализация контейнера сущностей. Управляет хранением компонентов (Archetype-based storage), создание/удаление сущностей, итерация по компонентам. Оптимизирован для кэш-локальности. |
| **`src/ecs/entity.rs`** | Определение типа `Entity` (ID + Generation). Гарантирует безопасность доступа к удалённым сущностям через механизм поколений (Generation), предотвращая use-after-free. |
| **`src/ecs/component.rs`** | Трейт `Component` и реализации для стандартных данных (Transform, Velocity, Mesh, RigidBody). Маркирует типы данных, которые могут быть прикреплены к сущностям. |
| **`src/ecs/system.rs`** | Трейт `System` и планировщик систем. Определяет интерфейс для логики обработки (`run(&mut self, world: &mut World)`). Управляет порядком выполнения систем. |
| **`src/ecs/job_system.rs`** | **Критический модуль параллелизма.** Реализует систему задач (Job System) на базе потоков (`std::thread`). Распределяет вычислительно сложные задачи (физика, скиннинг) по ядрам CPU. *Полностью безопасная реализация без unsafe блоков, использует Mutex для синхронизации.* |

### 🌍 Генерация мира и чанки

| Файл | Описание |
|------|----------|
| **`src/world/mod.rs`** | Агрегатор модулей мира. Экспортирует `ChunkManager`, `TerrainGenerator`, `PropSpawner`. |
| **`src/world/chunk_manager.rs`** | Управляет жизненным циклом чанков (загрузка/выгрузка). Реализует пул активных чанков вокруг игрока, асинхронную загрузку с диска и выгрузку из памяти. Координирует потоковую передачу данных. |
| **`src/world/terrain_generator.rs`** | Процедурная генерация ландшафта. Использует шум Перлина/Симплекса для создания высотной карты. Рассчитывает нормали, типы биома и базовую геометрию террейна для каждого чанка. |
| **`src/world/prop_spawner.rs`** | Размещение объектов (деревья, камни, здания) на террейне. Использует маски биомов и правила размещения (уклон, высота) для процедурной расстановки Props. Интегрируется с системой коллизий. |
| **`src/world/lod_system.rs`** | Система уровней детализации (LOD). Автоматически переключает меши чанков и объектов в зависимости от расстояния до камеры. *Реализован гистерезис для устранения мерцания ("popcorn effect") и троттлинг обновлений.* |

### ⚛️ Физический движок (Универсальный)

| Файл | Описание |
|------|----------|
| **`src/physics/mod.rs`** | Главный модуль физики. Экспортирует все подсистемы: `PhysicsWorld`, `Vehicle`, `Helicopter`, `Collider`. |
| **`src/physics/physics_world.rs`** | Основной контейнер физической симуляции. Управляет списком тел, гравитацией, широкой и узкой фазой коллизий. Выполняет интеграцию шага симуляции (Fixed Timestep). |
| **`src/physics/rigidbody.rs`** | Компонент твёрдого тела. Хранит массу, инерцию, позицию, ориентацию, линейную и угловую скорости. Реализует интеграторы (Symplectic Euler, RK4). |
| **`src/physics/collider.rs`** | Геометрия коллизий. Поддерживает сферы, боксы (AABB/OBB), выпуклые меши. Реализует тесты пересечений и генерацию контактных точек. |
| **`src/physics/spatial_hash.rs`** | Пространственное хэширование для оптимизации широкой фазы. *Оптимизировано: использует обратную величину размера ячейки вместо деления, поддерживает большие AABB, исключает дубликаты.* |
| **`src/physics/vehicle.rs`** | Физика наземного транспорта. Модель подвески (пружина+демпфер), сцепление колес (Pacejka), двигатель, трансмиссия. Поддерживает автомобили и грузовики. |
| **`src/physics/helicopter.rs`** | **Универсальная физика вертолётов.** <br> - **Конфигурируемость:** Все параметры (масса, радиус ротора, шаг лопастей, мощность двигателя) задаются через `HelicopterConfig`. <br> - **BEM Theory:** Расчёт подъёмной силы по элементам лопасти с учётом закрутки и потерь.<br> - **Двигатели:** Поддержка поршневых, турбовальных и электрических двигателей через трейт `EngineModel`.<br> - **Оптимизация:** Кэширование синусов/косинусов азимута, блочные вычисления сил.<br> - **Безопасность:** Полный контроль устойчивости, защита от численного взрыва. |
| **`src/physics/async_physics.rs`** | Асинхронный запуск физики в отдельном потоке. Реализует двустороннюю связь через каналы (MPSC). Синхронизирует состояние между физическим шагом и рендерингом (интерполяция). Поддерживает запросы состояния для вертолётов и авто. |
| **`src/physics/arena_allocator.rs`** | Высокоскоростной аллокатор памяти для физических объектов. *Безопасная реализация с проверкой поколений (Generations) для предотвращения висячих указателей.* |

### 🎨 Графический движок и RHI

| Файл | Описание |
|------|----------|
| **`src/graphics/mod.rs`** | Агрегатор графических модулей. Экспортирует `Renderer`, `Mesh`, `Shader`, `Texture`. |
| **`src/graphics/renderer.rs`** | Высокоуровневый интерфейс рендеринга. Управляет камерами, светом, очередью отрисовки. Сортирует объекты по материалу для минимизации переключений состояний (State Changes). |
| **`src/graphics/rhi/mod.rs`** | Абстракция низкоуровневого интерфейса (RHI). Определяет общие трейты `Device`, `Context`, `Buffer`, `Texture` для бэкендов. |
| **`src/graphics/rhi/gl.rs`** | Реализация RHI для OpenGL 4.5+. Использует `glow` для безопасных вызовов. Маппинг общих типов в вызовы GL. |
| **`src/graphics/rhi/vulkan/mod.rs`** | Модуль Vulkan бэкенда. Содержит логику инициализации_instance, device, swapchain. |
| **`src/graphics/rhi/vulkan/device_vk.rs`** | Управление устройством Vulkan. *Исправлено:* корректное создание очередей (graphics_queue_info). Реализует аллокацию памяти и командных буферов. |
| **`src/graphics/shader.rs`** | Менеджер шейдеров. Компиляция GLSL/HLSL, линковка программ, управление uniform-переменными. Поддерживает горячую перезагрузку (Hot Reload). |
| **`src/graphics/mesh.rs`** | Управление геометрией. Загрузка вершин, индексов, создание GPU-буферов. Поддержка скиннинга и морфинга для LOD. |
| **`src/graphics/texture.rs`** | Загрузка и управление текстурами. Поддержка форматов (PNG, KTX), мипмаппинг, сэмплеры. |
| **`src/graphics/camera.rs`** | Матрицы вида и проекции. Поддержка перспективной и ортографической камеры. Расчёт Frustum Culling. |
| **`src/graphics/lighting.rs`** | Модель освещения. Directional, Point, Spot lights. Реализация PBR (Metallic/Roughness) и Tone Mapping (ACES). |

### 🛠 Утилиты и вспомогательные модули

## 🏗 Зависимости и требования

Проект требует **Rust Stable** (последняя версия).
Основные крейты: `nalgebra` (математика), `glow` + `glutin` (OpenGL), `serde` (сериализация), `rodio` (аудио), `noise` (генерация).

Для сборки требуется установленный Vulkan SDK (для бэкенда Vulkan) или драйверы OpenGL 4.5+.
